# SiteHeader

L'en-tête du site produit : la marque Lafia, les quatre ancres et le bouton principal « Ouvrir mon carnet ». Collant sur desktop ; sous 880px, les ancres passent dans un bouton menu.

**À fournir :** `links` (`[{label, href}]`, par défaut *Vision*, *Comment ça marche*, *Services*, *Demain*), `ctaHref`, `ctaLabel`, `homeHref`, `sticky`.
