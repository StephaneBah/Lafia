# CodeField

Le champ code carnet : une case par caractère, remplie chiffre par chiffre, portée par un seul vrai champ (le collage et le remplissage automatique fonctionnent).

**À fournir :** `length` (6 par défaut), `value`/`onChange` ou `defaultValue`, `numeric` pour un code tout chiffres, `label` (« Code carnet » par défaut), `hint` (indique où le code est imprimé sur le reçu), `error`.

- À la connexion, l'associer à l'illustration du reçu qui s'éclaire là où le code est imprimé.
