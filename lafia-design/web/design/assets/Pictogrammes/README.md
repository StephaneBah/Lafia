# Pictogrammes

Jeu propre à Lafia, dessiné dans le style des illustrations. Grille 48×48, zone utile 4–44, contours `encre` #121212 de 3px, extrémités et jonctions rondes, aplats plats : `blanc`, `pervenche`, `illu-soleil` (#F2B544), `bleu-royal`, sarcelle `status-paye-fg`, rouge `status-danger-fg`. Aucun dégradé. Lisibles en noir seul.

- Traitement : `matin`, `midi`, `soir`, `nuit`, `avant-repas`, `apres-repas`, `comprime`, `comprime-demi`, `jours`.
- États d'ordonnance : `a-payer`, `paye`, `a-retirer`, `retire-partie`, `retire`.
- Sécurité : `allergie`, `urgence`, `consultation` (qui a consulté mon dossier).

Toujours accompagnés du mot à l'écran. Chaque SVG porte son libellé français en `<title>`.
