# SiteHeader

L'en-tête du site produit : la marque Lafia, les quatre ancres et le bouton principal « Ouvrir mon carnet ». Collant sur desktop ; sous 880px, les ancres passent dans un bouton menu.

**À fournir :** `ctaHref` (l'application citoyen, `adresse(domaine, "citoyen")`), `links` (`[{label, href}]`, par défaut *Vision*, *Comment ça marche*, *Services*, *Demain*), `ctaLabel`, `homeHref`, `sticky`, `animateLogo` (le point du « i » se pose en dernier, à l'arrivée sur le site).
