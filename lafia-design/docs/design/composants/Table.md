# Table

Un tableau dense et utilisable au clavier pour les écrans professionnels.

**À fournir :** `columns` `[{key, label, align:'end', mono}]` (`mono` pour les identifiants, `end` pour les montants), `rows` (objets par clé de colonne, `id`, `selected` facultatifs), `caption`, `dense`, `loading` (lignes squelettes), `empty` (message).

- Montants alignés à droite en chiffres tabulaires : `12 500 FCFA`. Dates `25/09/2026`.
