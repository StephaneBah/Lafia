# Logo

- `lafia-logo.svg` — la version retenue (variante B) : mot `bleu-royal` (#3648C0), point `terre` (#C2562B). Sur surfaces claires.
- `lafia-logo-blanc.svg` — mot blanc, point `terre`. Sur `bleu-royal`, `bleu-denim` et `ardoise`.
- `lafia-logo-noir.svg` — mot et point encre #121212. Reçu imprimé, fax, tampon.
- `lafia-icone.svg` — forme compacte : « L » blanc et son point sur carré `bleu-royal` arrondi (rx 14/64). Favicon, icône d'app ; lisible à 16px.
- `lafia-point.svg` — le point seul sur carré royal : avatar, écran de chargement de marque.
- `lafia-variante-A/B/C.svg` — les trois pistes étudiées. A : 800, approche −0,02em, point ×1,2. B (retenue) : 800, approche −0,045em, point ×1,45, relevé. C : 700, approche −0,01em, point ×1,12.

Encres fixes (les SVG ne suivent pas `currentColor`). Mot vectorisé depuis Atkinson Hyperlegible Next ExtraBold ; le point du « i » est un cercle parfait redessiné.
