# Icônes

Sous-ensemble de Phosphor Icons (MIT) utilisé par les composants : graisse `bold` (`*-bold.svg`) pour l'interface, `duotone` (`*-duotone.svg`) à côté des illustrations. Encre #121212 fixe dans ces fichiers ; dans le code, passer par le composant `Icon`, qui suit `currentColor`. Toute autre icône vient du paquet `@phosphor-icons/core`, jamais d'une autre famille.
